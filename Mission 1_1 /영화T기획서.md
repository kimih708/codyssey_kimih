# 영화T 기획서

## 1. 프로젝트 개요

**프로젝트명:** 영화T  
**목적:** 사용자가 영화들을 직접 티어별로 배치해 자신의 영화 취향을 공유할 수 있는 웹페이지를 만든다.

사용자는 영화 목록을 보고, 원하는 영화를 드래그해서 티어 영역에 배치할 수 있다.  
완성된 티어리스트는 친구에게 공유할 수 있으며, 친구는 보기 전용 화면에서 티어리스트를 확인하고 반응할 수 있다.

---

## 2. 주요 사용자

### 작성자

- 영화 티어리스트를 만드는 사람
- 영화 목록을 필터링할 수 있음
- 영화를 티어 영역에 드래그해서 배치 가능
- 저장 후 다시 수정 가능
- 공유 링크 생성 가능

### 친구 / 방문자

- 공유받은 티어리스트를 볼 수 있음
- 수정은 불가능
- 필터 기능 사용 가능
- 이미지 저장 가능
- 댓글과 이모지 반응 가능

---

## 3. 화면 구성

총 3개 화면으로 구성한다.

### 1. 시작 화면

- 프로젝트 소개
- 티어리스트 만들기 버튼
- 기존 공유 링크 접속 시 보기 화면으로 이동

### 2. 편집 화면

작성자가 티어리스트를 만드는 화면이다.

주요 기능:

- 영화 목록 표시
- 관람등급 필터
- 장르 필터
- 영화 카드 드래그
- 티어 영역에 영화 배치
- 저장 버튼
- 저장 후 재수정 가능
- 공유 링크 생성

### 3. 보기 화면

친구가 공유 링크로 접속했을 때 보는 화면이다.

주요 기능:

- 작성자가 만든 티어리스트 보기
- 편집 불가
- 필터 기능
- 이미지 저장
- 댓글 작성
- 이모지 반응

## 6. 영화 데이터 구조

Supabase의 `movies` 테이블에 영화 데이터를 저장한다.

### movies 테이블 예시

| 컬럼명 | 설명 |
|---|---|
| id | 영화 고유 ID |
| title | 영화 제목 |
| poster_url | 포스터 이미지 URL |
| rating | 관람등급 |
| genre | 장르 |
| sort_order | 정렬 순서 |

### 현재 상태

- 영화 30개 데이터 준비 완료
- `poster_url`은 아직 실제 URL 확인 필요
- `rating`은 아직 정확한 국내 관람등급 확인 필요
- 개발 단계에서는 `확인 필요` 값 사용

## 8. 현재까지 구현한 기능

### 1. Supabase 영화 데이터 불러오기

`movies` 테이블에서 영화 데이터를 가져와 화면에 카드 형태로 표시한다.

영화 카드에는 다음 정보가 표시된다.

- 포스터
- 제목
- 관람등급
- 장르

포스터 URL이 없을 경우에는 `포스터 없음` 영역을 보여준다.

---

### 2. 영화 카드 UI

영화 목록은 카드 형태로 보여준다.

카드 구성:

- 포스터 영역
- 영화 제목
- 관람등급
- 장르

반응형 그리드로 구성해 화면 크기에 따라 자동으로 줄바꿈된다.

---

### 3. 관람등급 필터

`movies` 테이블의 `rating` 값을 기준으로 필터 옵션을 자동 생성한다.

예시:

- 전체
- 확인 필요
- 전체 관람가
- 12세 관람가
- 15세 관람가
- 청소년 관람불가

현재는 관람등급이 대부분 `확인 필요` 상태이다.

---

### 4. 장르 필터

`movies` 테이블의 `genre` 값을 기준으로 필터 옵션을 자동 생성한다.

예시:

- 전체
- SF
- 드라마
- 로맨스
- 액션
- 애니메이션
- 공포
- 스릴러
- 코미디
- 판타지

---

### 5. 필터 초기화

필터 초기화 버튼을 누르면 다음 상태로 돌아간다.

- 관람등급: 전체
- 장르: 전체

---

### 6. 드래그 앤 드롭 기능

영화 카드를 드래그해서 티어 영역에 배치할 수 있다.

드롭 가능한 영역:

- 명작
- 재밌음
- 보통
- 별로
- 영화 목록 영역

티어에 넣은 영화도 다시 영화 목록으로 되돌릴 수 있다.
