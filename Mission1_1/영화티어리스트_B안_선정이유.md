# 영화 티어리스트 시안 비교 — B안(`영화_B_초안.html`) 선정 이유

## 1. 비교 대상 개요

| 구분 | A안 (`영화_A_초안.html`) | B안 (`영화_B_초안.html`) |
|---|---|---|
| 서비스명 | 영화 티어리스트 (이름 없음) | **영화T** (브랜드명·로고 있음) |
| 파일 상태 | 약 8KB, 스크립트가 영화 데이터 20번째 줄에서 끊김 (미완성) | 약 49KB, 처음부터 끝까지 완성된 코드 |
| 화면 구성 | 단일 화면 (필터 + 티어 보드 + 영화 목록 + 버튼) | 3개 화면 (시작 / 편집 / 보기 전용) |
| 영화 수 | 데이터 20편만 확인됨 (기획 30편) | 30편 모두 수록 |
| 실제 동작 여부 | 화면 틀만 있고 드래그·필터·저장 로직 없음 | 드래그, 필터, 저장, 공유, 댓글, 이미지 저장 모두 동작 |

## 3. 항목별 상세 비교

### 3-1. 영화 티어리스트로서의 형식

| 비교 요소 | A안 | B안 | B안 선정 이유 |
|---|---|---|---|
| 티어 단계 | 명작 · 재밌음 · 보통 · 별로 (4단계) | 명작 · 재밌음 · 보통 · 별로 (4단계) | 단계는 같음 |
| 티어 라벨 | 이름만 표시, 폭 70px | 이름 + 설명 문구(예: "가장 높은 평가"), 폭 120px | 각 칸의 의미가 바로 이해됨 |
| 티어 줄 높이 | 최소 90px | 최소 120px | 여러 편을 놓아도 덜 답답함 |
| 영화 카드 | 72px 소형 카드, 이모지 + 제목 | 포스터 비율(2:3) 카드, 제목 + 관람등급 + 장르 칩 | 실제 영화 포스터 형식에 가까워 티어리스트다운 모양 |
| 포스터 처리 | 이모지로 대체 | `poster_url`이 있으면 이미지, 없으면 장르 색 그라데이션 + 제목 | 나중에 포스터만 넣으면 바로 완성형이 됨 |
| 티어 내 순서 | 없음 | 카드 앞/뒤로 끼워 넣어 같은 티어 안에서도 순서 조정 | "줄 세우기"라는 티어리스트 본래 재미를 살림 |
| 제목·작성자 | 없음 | 티어리스트 제목, 만든 사람 입력 가능 | 나만의 리스트라는 소유감 부여 |

### 3-2. 기능

| 기능 | A안 | B안 | B안 선정 이유 |
|---|---|---|---|
| 드래그 앤 드롭 | 영역만 있고 동작 코드 없음 | 구현됨 (끌 때 반투명, 놓을 칸 강조 표시) | 핵심 조작이 실제로 됨 |
| 모바일 조작 | 없음 (터치 드래그 미지원) | 카드 탭 → 칸 탭으로 이동, 상단에 "선택됨" 안내 바 | 휴대폰에서도 사용 가능 |
| 키보드 조작 | 없음 | Enter로 선택, 숫자 1~4 티어 / 0 목록 / Esc 취소 | 접근성 확보 |
| 관람등급·장르 필터 | 칩 버튼 자리만 있음 (생성 코드 없음) | 드롭다운 필터, 남은 영화 수 / 표시 수 안내 | 필터가 실제로 동작하고 결과를 숫자로 알려줌 |
| 목록으로 되돌리기 | 전체 초기화 버튼만 | 개별 카드를 목록으로 되돌리기 + 전체 되돌리기(확인창) | 실수를 쉽게 고칠 수 있음 |
| 저장 | 버튼만 있음 | 브라우저 저장, "저장 안 된 변경 있음 / 저장됨" 상태 표시, 나가기 전 경고 | 작업 손실 방지 |
| 불러오기·이어서 수정 | 버튼만 있음 | 시작 화면에 마지막 저장 시각·제목·배치 수 표시 후 "이어서 수정하기" | 재방문 시 바로 이어서 작업 |
| 공유 | 없음 | 서버 없이 링크 하나에 티어리스트 전체를 담아 공유 | 기획 목적인 "친구에게 공유" 달성 |
| 보기 전용 화면 | 없음 | 받은 사람은 수정 불가 화면으로 열람, 필터로 골라보기 | 원본 훼손 없이 감상 |
| 반응·댓글 | 없음 | 이모지 반응 6종, 이름·댓글 작성 및 삭제 | 공유 후 소통 요소 |
| 이미지 저장 | 없음 | 티어리스트를 PNG(2배 해상도)로 저장, 필터 적용 상태도 반영 | SNS·메신저에 바로 올릴 수 있음 |
| 안내 메시지 | 토스트 영역만 | 저장·복사·필터 초기화·오류 등 상황별 안내 | 사용자가 결과를 즉시 확인 |

### 3-3. 목적 달성 정도

| 기획 목적 | A안 | B안 |
|---|---|---|
| 영화를 내 취향대로 등급 매기기 | 화면 틀만 있어 실제로는 배치 불가 | 드래그·탭·키보드로 배치 가능 |
| 30편 영화 중 원하는 영화 찾기 | 20편까지만 데이터 확인, 필터 미동작 | 30편 전체 + 관람등급·장르 필터 동작 |
| 만든 결과 저장·수정 | 미구현 | 저장, 상태 표시, 이어서 수정, 새로 만들기 |
| 친구에게 공유하기 | 기능 없음 | 공유 링크, 링크 복사, 받은 링크 붙여 넣어 열기 |
| 친구의 반응 받기 | 기능 없음 | 이모지 반응 + 댓글 |
| **종합** | **목적 달성 불가 (미완성 초안)** | **기획 흐름(고르기 → 배치 → 저장 → 공유 → 반응) 전체 달성** |

### 3-4. 디자인 — 색상

| 비교 요소 | A안 | B안 | B안 선정 이유 |
|---|---|---|---|
| 배경 톤 | 남색 계열 어두운 배경 (#0f1221) | 무채색에 가까운 어두운 배경 (#0e1014) | 영화관 같은 차분한 분위기, 카드 색이 더 돋보임 |
| 강조색 | 보라 계열 (#6c7bff) | 빨강 계열 (#ff5a5f) | 영화·극장 이미지와 어울리고 주요 버튼이 눈에 띔 |
| 티어 색 | 빨강 → 주황 → 하늘 → 회색 | 금색 → 초록 → 파랑 → 회색 | 명작=금색으로 "최고 등급" 의미가 직관적, 색 간 구분이 뚜렷 |
| 영화 카드 색 | 영화마다 임의의 단색 | 장르별 고정 그라데이션 (SF 파랑, 로맨스 분홍, 공포 회흑 등 9종) | 색만 봐도 장르를 알 수 있어 정보 전달력이 높음 |
| 상태 색 | 토스트 초록 1종 | 저장 안 됨=주황, 선택 카드=주황 테두리, 놓을 칸=강조색 테두리 | 현재 상태를 색으로 구분해 알려줌 |

### 3-5. 디자인 — 구성·레이아웃

| 비교 요소 | A안 | B안 | B안 선정 이유 |
|---|---|---|---|
| 첫 화면 | 바로 작업 화면 | 시작 화면(서비스 소개 + 3단계 사용법 + 공유 링크 열기) | 처음 온 사람도 사용법을 바로 이해 |
| 화면 흐름 | 한 페이지에 모든 요소 나열 | 시작 → 편집 → 보기로 목적별 화면 분리 | 화면마다 할 일이 명확 |
| 상단 바 | 없음 (단순 제목) | 고정 상단 바에 로고, 저장 상태, 저장·공유 버튼 | 스크롤해도 핵심 버튼 접근 가능 |
| 필터 위치 | 티어 보드 위 별도 박스 | 영화 목록 머리에 붙어 있음 | 필터가 영향을 주는 영역과 가까워 이해가 쉬움 |
| 빈 칸 안내 | 없음 | "여기에 영화를 놓으세요", "모든 영화를 배치했어요!" 등 | 빈 상태에서도 다음 행동을 안내 |
| 글꼴 | 시스템 기본 한글 글꼴 | Pretendard 우선 + 대체 글꼴 지정, 제목은 큰 굵은 글씨 | 더 정돈되고 현대적인 인상 |
| 인터랙션 효과 | 거의 없음 | 버튼·카드 호버, 누름 효과, 토스트 슬라이드 등 | 조작감이 자연스러움 |

## 4. 참고 — A안의 장점과 B안의 보완점

공정한 비교를 위해 A안이 앞선 부분과, B안을 최종본으로 만들 때 손볼 점을 함께 정리합니다.

| 구분 | 내용 |
|---|---|
| A안 장점 | 관람등급 값(전체·12·15·18)이 이미 입력되어 있음 |
| A안 장점 | 영화별 이모지로 포스터 없이도 친근한 느낌 |
| A안 장점 | 칩 버튼 필터는 드롭다운보다 한 번에 눌러 바꾸기 쉬움 |
| B안 보완점 | 관람등급이 모두 '확인 필요' → 실제 등급 입력 필요 (A안 데이터 참고 가능) |
| B안 보완점 | 포스터 이미지 미입력 → `poster_url` 채우기 필요 |
| B안 보완점 | 댓글·반응이 각자 브라우저에만 저장되어 만든 사람에게 전달되지 않음 → 서버(Supabase 등) 연동 필요 |
| B안 보완점 | 포커스 색 변수(`--accent2`)가 정의되지 않아 대체값으로 표시됨 → 변수 정의 권장 |

## 5. 결론

A안은 화면 틀과 스타일만 갖춘 **미완성 초안**으로, 스크립트가 중간에 끊겨 드래그·필터·저장이 동작하지 않고 공유 기능도 없습니다.

B안은 **시작 → 편집 → 보기**의 3단계 화면으로 사용 흐름이 명확하고, 30편 전체 데이터와 드래그·탭·키보드 배치, 필터, 저장·이어서 수정, 링크 공유, 반응·댓글, 이미지 저장까지 갖추어 **"나만의 영화 취향을 정리하고 친구와 공유한다"는 기획 목적을 처음부터 끝까지 달성**합니다. 또한 금색(명작)부터 회색(별로)까지 의미가 분명한 티어 색, 장르별 카드 색 체계, 모바일 반응형, DB 연동을 고려한 데이터 구조로 디자인과 확장성 모두 앞섭니다.

따라서 다음 단계 개발의 기준 시안으로 **`영화_B_초안.html`을 선정**하며, 관람등급·포스터 데이터 입력과 댓글·반응의 서버 저장을 우선 보완 과제로 둡니다.
