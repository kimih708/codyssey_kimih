# 🎬 영화 티어리스트 웹페이지 개발 기록

## 📌 프로젝트 개요

- **프로젝트명**: 영화 티어리스트 (가칭: 영화T)
- **목적**: 친구들과 서로의 영화 취향을 공유하기 위한 티어리스트 웹페이지
- **형태**: 단일 HTML 파일 (브라우저에서 바로 실행)
- **최종 기술 스택**: Supabase (추후 분리 예정)

---

## 🎯 사용자 및 목적 정의

- **주 사용자**: 영화를 좋아하는 일반 사용자
- **사용 목적**:
  - 내가 본 영화에 등급(티어)을 매긴다
  - 친구에게 링크로 공유해 취향을 나눈다
  - 친구는 보기만 가능하고 댓글·반응으로 소통한다

## 🧩 주요 기능 정의

### 1. 필터링
- **관람등급** 필터 (전체 / 12세 / 15세 / 18세 등)
- **장르** 필터 (SF, 드라마, 로맨스, 액션, 애니, 공포, 코미디, 판타지 등)
- 필터 초기화 버튼 제공

### 2. 화면 구성 (3개)
1. **시작 화면**: 티어리스트 만들기 시작 안내
2. **편집 화면**: 영화 드래그 & 드롭으로 티어 배치
3. **보기 화면**: 완성된 티어리스트를 친구가 감상

### 3. 티어 구성 (4단계)
| 티어 | 의미 | 색상 |
|------|------|------|
| S | 명작 | 빨강 |
| A | 재밌음 | 주황 |
| B | 보통 | 파랑 |
| C | 별로 | 회색 |

### 4. 드래그 & 드롭
- 영화 카드를 티어 영역으로 드래그해 배치
- 티어 간 이동 가능
- 다시 목록으로 되돌리기 가능

### 5. 저장 및 공유
- **저장 버튼** 방식 (자동 저장 X)
- **공유 링크 분리**:
  - 편집용 링크: 작성자만 재수정 가능
  - 보기용 링크: 친구에게 공유 (읽기 전용)

### 6. 친구(열람자) 기능
- 티어리스트 **보기 전용**
- **필터** 적용 가능
- **이미지로 저장** 기능
- **댓글 + 이모지 반응** 가능

### 7. 작성자 기능
- 저장 후 **재수정 가능**
- 편집 링크를 통해 언제든 돌아와서 수정

### 8. 반응형
- 모바일/태블릿/PC 모두 지원
- 모바일에서도 드래그 동작 가능
