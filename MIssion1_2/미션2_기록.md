# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명:

  Claude (Opus 5.5)/ 대화내용캡처01.png, 대화내용캡처02.png, 대화내용캡처03.png, 대화내용캡처04.png

- 좁혀서 적은 한 문장:
 제목에 띄어쓰기가 있는 영화 카드(토이 스토리, 센과 치히로의 행방불명, 어벤져스: 엔드게임)는 누르거나 끌어도 등급 칸으로 옮겨지지 않는다.
- **좁히려고 해 본 것과 결과:**
  - 처음 8개 카드를 하나씩 눌러 봄 → 띄어쓰기가 없는 5개(기생충, 인터스텔라, 라라랜드, 범죄도시, 타이타닉)만 옮겨짐
  - `토이스토리`(붙여 씀)와 `해리 포터`(띄어 씀)를 새로 추가함 → 붙여 쓴 카드만 옮겨짐
  - 결론: 띄어쓰기 유무가 되는 경우와 안 되는 경우를 가름
- **AI가 말한 원인과, 그 설명을 직접 확인한 결과:**
  - 원인: 카드를 HTML 글자로 이어 붙여 만들 때 이름표(`data-id`)에 따옴표가 없어, 첫 띄어쓰기에서 이름표가 잘렸다(‘토이 스토리’ → ‘토이’). 잘린 이름으로는 목록에서 영화를 찾지 못해 아무 일도 일어나지 않았다.
  - 확인: 개발자 도구 ‘검사’에서 `data-id="토이" 스토리=""`로 쪼개진 것을 확인했다. 콘솔에서 아래 코드를 실행해 띄어 쓴 제목만 이름표가 첫 단어로 잘린 것을 확인했다.

    ```js
    [...document.querySelectorAll('.card')].map(c => c.textContent + ' → ' + c.dataset.id)
    ```

|---|---|---|
| 영화_수정전.html | (원본) `card()`에서 HTML 문자열을 이어 붙여 카드를 만들었고, `data-id`에 따옴표가 없었음 | 띄어 쓴 제목 3개와 새로 추가한 띄어 쓴 제목은 선택·이동 안 됨 |

### 바꾼 코드

**수정 전**

```js
const template = document.createElement('template');
template.innerHTML = '<button type="button" class="card" draggable="true" data-id=' + item.id + '>' + item.title + '</button>';
const element = template.content.firstElementChild;
```

**수정 후**

```js
const element = document.createElement('button');
element.type = 'button';
element.className = 'card';
element.draggable = true;
element.dataset.id = item.id;
element.textContent = item.title;
```
