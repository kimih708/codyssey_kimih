# 나무가 아픈가요? — 가로수 병해 진단 체크리스트

> 사용한 AI 서비스와 모델: Claude (claude.ai) / Claude Opus 5.5
> 작성 방식: AI가 4단계로 질문하고(대상·목적 → 화면·동작 → 자료 → 기능·계산), 답변을 기획서로 정리한 뒤 직접 검토·수정

## 대상 사용자

- 조경·가로수 관리 실무자 (지자체 가로수 담당자, 조경 관리 업체 직원)
- 현장에서는 스마트폰으로, 사무실에서는 PC로 비슷한 비율로 사용합니다.

## 사용 목적

- 가로수에 이상 증상이 보일 때 **수종과 증상을 체크해 의심 병해 후보를 빠르게 좁힙니다.**
- 후보마다 **위험도 등급(관찰 / 조치 필요 / 즉시 전문가)**을 확인해 직접 관리할지, 나무병원(나무의사)에 의뢰할지 판단합니다.
- 줄기 썩음, 기울어짐처럼 **쓰러짐(도복) 사고 위험이 있는 증상은 따로 경고**를 받아 우선 조치합니다.
- 결과를 복사하거나 인쇄해 업무 일지·보고서에 붙입니다.

## 화면 구성과 동작

### 필수 기능

화면은 위에서 아래로 다음 순서로 구성합니다. 모바일과 PC 모두 한 열로 읽히는 반응형으로 만듭니다.

1. **머리말**: 제목 '나무가 아픈가요?', 한 줄 안내, "이 결과는 참고용 1차 진단입니다" 문구
2. **① 수종 선택**: 은행나무 / 벚나무 / 느티나무 / 양버즘나무(플라타너스) / 이팝나무 / 배롱나무 / 기타·모름 중 하나를 버튼으로 선택
   - 수종을 선택하면 해당 수종의 병해와 공통 병해만 진단 대상이 됩니다. (아래 '병해 목록' 표의 '대상 수종' 기준)
   - '기타·모름'을 선택하면 13개 병해 전체가 진단 대상이 됩니다.
   - **수종을 선택해야 ② 증상 체크 항목이 나타납니다.** 선택 전에는 "① 수종을 먼저 선택하면 그 수종에 맞는 증상 체크 항목이 나타납니다." 안내만 표시합니다.
3. **② 증상 체크 (수종별 구성)**: 선택한 수종의 **진단 대상 병해에 연결된 증상**과 **도복 위험 증상(S13~S16, 모든 수종 공통)**만 체크 항목으로 보여 줍니다. 수종별 항목은 아래 '수종별 증상 체크 항목' 표를 따릅니다.
   - 체크 목록 위에 "수종 이름 — 진단 대상 병해 ○개 · 증상 체크 항목 ○개"와 진단 대상 병해 이름을 표시합니다.
   - **다른 수종으로 바꾸면 증상 체크를 초기화합니다.** 체크 목록을 새 수종에 맞게 다시 구성하고, 이전 수종에서 한 체크는 두 수종에 공통인 증상까지 모두 해제합니다. 기록 칸 내용과 이전 진단 결과도 지웁니다(다른 나무의 관찰 기록이 섞이지 않도록). 지운 내용이 있었으면 "수종을 바꿔 이전 증상 체크와 기록을 초기화했습니다."로 알립니다.
   - 이미 선택된 수종 버튼을 다시 누르면 아무것도 바뀌지 않습니다.
   - 어떤 부위에 해당 수종의 목록 증상이 없으면 그 영역에 "목록 증상이 없습니다. 보이는 증상은 아래에 기록하세요."를 표시합니다.
   - 체크 항목은 **잎 / 가지 / 줄기 / 뿌리·주변 4개의 별도 영역(상자)**으로 나눠 보여 줍니다.
   - 영역마다 테두리 색과 이름표(🍃 잎, 🌿 가지, 🪵 줄기, 🌱 뿌리·주변), 증상 개수를 표시합니다. PC에서는 2열, 스마트폰에서는 1열로 배치합니다.
   - 도복 관련 증상(S13~S16)에는 ⚠ 표시를 붙입니다.
   - **목록에 없는 증상 기록**: 영역마다 아래쪽에 '목록에 없는 ○○ 증상 기록' 입력 칸(최대 300자)을 둡니다. 선택한 수종의 진단 목록에 없는 증상을 직접 적을 수 있습니다.
   - 기록한 내용은 **일치율 계산에 포함하지 않고**, 결과 화면·[결과 복사]·[인쇄]에 '기록한 기타 증상'으로 함께 나옵니다. 나무병원 상담 시 전달하는 용도입니다.
4. **버튼 줄**: [진단하기] [초기화]
   - [진단하기]를 누르면 아래 ③ 결과가 표시됩니다. 체크만 바꿔서는 결과가 바뀌지 않습니다.
   - [초기화]를 누르면 수종 선택, 모든 체크, 기록 칸 내용, 결과가 지워지고 증상 체크 영역은 수종 선택 전 안내로 돌아갑니다.
5. **③ 진단 결과**
   - **도복 경고 배너**: S13~S16 중 하나라도 체크했다면 일치율과 관계없이 결과 맨 위에 빨간 배너로 "쓰러짐 위험 — 주변 통행을 통제하고 즉시 전문가 점검"을 표시합니다.
   - **후보 카드 최대 3개**: 일치율이 높은 순서로 병해 이름, 일치율(예: `2/3 (67%)`), 위험도 색 배지(초록 관찰 / 노랑 조치 필요 / 빨강 즉시 전문가), 맞은 증상 목록, 관리 요령, 방제 적기(월), 사진 1장과 사진 출처를 표시합니다.
   - 정렬: ① 일치율 높은 순 → ② 같으면 위험도 높은 순 → ③ 같으면 맞은 증상 수가 많은 순 → ④ 그래도 같으면 병해 ID 순(D1, D2 …)
   - 일치율이 0%인 병해는 표시하지 않습니다.
   - 일치하는 병해가 없으면 "일치하는 병해가 없습니다. 증상이 계속되면 나무병원에 상담하세요."를 표시합니다.
   - **위험도 등급 안내**: 후보 카드 아래에 세 등급의 뜻과 대응을 표시합니다. 이번 결과 카드에 나온 등급은 테두리와 "← 이번 결과" 표시로 강조합니다.
     - 관찰(초록): 당장 위험은 낮음. 증상이 번지는지 지켜보며 병든 잎 정리, 통풍 관리 같은 기본 관리
     - 조치 필요(노랑): 그대로 두면 나무가 약해지거나 피해가 번질 수 있음. 방제 적기에 맞춰 관리·방제, 약제 사용은 나무병원과 상담
     - 즉시 전문가(빨강): 나무가 말라 죽거나 쓰러질 수 있음. 바로 나무병원(나무의사)에 진단 의뢰, 필요하면 주변 통행 통제
     - 안내 아래에 "빨간 '쓰러짐 위험' 배너는 등급과 별도로 S13~S16을 체크하면 항상 표시된다"는 설명을 붙입니다.
   - 기타 증상을 기록했다면 후보 카드 위에 '기록한 기타 증상' 상자로 부위와 내용을 보여 줍니다.
   - 수종을 고르지 않았거나, 증상을 하나도 체크하지 않고 기록도 하지 않은 채 [진단하기]를 누르면 결과 대신 "수종을 고르고, 증상을 1개 이상 체크하거나 기록하세요."를 표시합니다.
   - 체크 없이 기타 증상만 기록하고 [진단하기]를 누르면 기록 내용과 "일치하는 병해가 없습니다…" 문구를 표시합니다.
6. **결과 버튼 줄**: [결과 복사] [인쇄]
   - [결과 복사]: 진단 날짜, 수종, 체크한 증상, 기록한 기타 증상, 후보 3개(이름·일치율·위험도), 도복 경고 여부, 위험도 등급 한 줄 요약을 텍스트로 클립보드에 복사하고 "복사되었습니다"를 표시합니다.
   - [인쇄]: 브라우저 인쇄 창을 엽니다. 인쇄물에는 버튼을 숨기고 수종·체크 증상·결과만 나옵니다.
7. **병해 목록(미니 도감)**: 페이지 아래에 13개 병해를 접힌 목록으로 두고, 이름을 누르면 대표 증상·대상 수종·위험도·관리 요령이 펼쳐집니다. 체크 없이도 볼 수 있습니다.
8. **바닥글**: 자료 출처, 사진 출처·라이선스, 면책 문구

### 일치율 계산 방법

```
일치율 = (체크한 증상 중 그 병해의 증상 수) ÷ (그 병해의 전체 증상 수) × 100
```

- 소수점은 반올림해 정수(%)로 표시합니다. 예: 2/3 → 67%

## 완료 기준

- `기타·모름`을 선택하고 S1, S19를 체크한 뒤 [진단하기]를 누르면 첫 번째 카드에 **흰가루병 2/2 (100%) · 관찰(초록)**이 표시됩니다.
- `은행나무`를 선택하고 S7, S17을 체크한 뒤 [진단하기]를 누르면 첫 번째 카드에 **제설염 피해 2/3 (67%) · 조치 필요(노랑)**가 표시됩니다.
- 수종을 선택하기 전에는 증상 체크박스가 하나도 없고 "① 수종을 먼저 선택하면…" 안내만 보입니다.
- 각 수종을 선택하면 '수종별 증상 체크 항목' 표와 같은 개수의 체크박스가 나옵니다. (은행 9, 벚 16, 느티 12, 양버즘 14, 이팝 13, 배롱 13, 기타·모름 22)
- `벚나무`를 선택하면 S3(버즘나무방패벌레 증상)가 목록에 없고, `이팝나무`를 선택하면 S1(흰가루병 증상)이 목록에 없습니다.
- 모든 수종에서 도복 위험 증상 S13~S16이 보입니다.
- `벚나무`에서 S1, S11, S13을 체크하고 기록 칸에 글을 쓴 뒤 [진단하기]를 누르고 `느티나무`로 바꾸면, 느티나무에도 있는 S1, S11, S13을 포함해 **모든 체크가 해제**되고 기록 칸이 비며 이전 결과가 사라집니다. "수종을 바꿔 이전 증상 체크와 기록을 초기화했습니다." 안내가 나옵니다.
- 체크나 기록 없이 수종만 바꾸면 초기화 안내는 나오지 않습니다. 이미 선택된 수종 버튼을 다시 누르면 체크가 그대로 남습니다.
- `이팝나무`를 선택하고 S21, S22를 체크한 뒤 [진단하기]를 누르면 첫 번째 카드에 **이팝나무 녹병 2/2 (100%) · 조치 필요(노랑)**가 표시됩니다.
- `배롱나무`를 선택하고 S23, S6을 체크한 뒤 [진단하기]를 누르면 첫 번째 카드에 **주머니깍지벌레 2/2 (100%) · 조치 필요(노랑)**, 두 번째 카드에 **깍지벌레·그을음병 1/3 (33%)**이 표시됩니다.
- `배롱나무`를 선택하고 S24, S19를 체크한 뒤 [진단하기]를 누르면 첫 번째 카드에 **배롱나무 갈색점무늬병 2/2 (100%) · 관찰(초록)**이 표시됩니다.
- 수종 버튼에 소나무가 없고, 어느 수종에서도 솔잎·송진 증상이 나오지 않습니다.
- S13~S16 중 하나라도 체크하고 [진단하기]를 누르면 후보 카드 위에 **빨간 도복 경고 배너**가 표시됩니다. 해당 증상을 모두 해제하고 다시 누르면 배너가 사라집니다.
- 후보가 4개 이상 일치해도 카드는 **최대 3개**만 표시되고, 정렬 규칙(일치율 → 위험도 → 맞은 증상 수)을 따릅니다.
- [진단하기]로 결과가 나오면 후보 카드 아래에 **위험도 등급 안내**(관찰 / 조치 필요 / 즉시 전문가의 뜻과 대응)가 표시됩니다. 예: `은행나무` + S7, S17, S11이면 '조치 필요'와 '즉시 전문가' 줄에 "← 이번 결과"가 붙고 '관찰' 줄에는 붙지 않습니다.
- 증상을 하나도 체크하지 않고 기록도 하지 않은 채 [진단하기]를 누르면 "수종을 고르고, 증상을 1개 이상 체크하거나 기록하세요."가 표시됩니다.
- 증상 체크 화면에 잎·가지·줄기·뿌리·주변 4개 영역이 색이 다른 별도 상자로 나뉘어 보이고, 각 상자 아래에 기록 칸이 있습니다.
- `느티나무`를 선택하고 체크 없이 '잎' 기록 칸에 "잎에 검은 둥근 점"을 적은 뒤 [진단하기]를 누르면 결과에 **[잎] 잎에 검은 둥근 점**과 "일치하는 병해가 없습니다…"가 표시됩니다.
- 기록 칸에 `<b>` 같은 태그를 적어도 글자 그대로 표시되고 화면 모양이 바뀌지 않습니다.
- [초기화]를 누르면 수종 선택, 모든 체크, 기록 칸 내용, 결과, 경고 배너가 사라지고 증상 체크 영역에 수종 선택 안내가 다시 나옵니다.
- [결과 복사]를 누른 뒤 메모장에 붙여 넣으면 날짜·수종·체크 증상·기록한 기타 증상·후보 3개(이름·일치율·위험도)·도복 경고 여부가 들어 있습니다.
- [인쇄]를 누르면 인쇄 미리보기에 버튼 없이 수종·증상·결과만 나옵니다.
- 미니 도감에서 병해 이름을 누르면 설명이 펼쳐지고, 다시 누르면 접힙니다.
- 스마트폰 폭(약 375px)에서 가로 스크롤 없이 모든 체크박스와 버튼을 누를 수 있습니다.
- **반드시 지킬 조건**: 다른 파일, 로그인, 서버, API 키 없이 **HTML 파일 하나**를 브라우저로 열면 동작합니다. (사진만 인터넷 주소로 불러오며, 사진이 안 불러와져도 진단 기능은 동작합니다.)

- 진단 기록 저장: 나무 관리번호·날짜별 진단 결과를 브라우저에 저장하고 목록으로 보기
- 위치(GPS)·관리번호 기록: 진단 시 위치와 가로수 관리번호를 함께 기록해 관리대장과 연계
- 수종·병해 확대: 메타세쿼이아·회화나무 등 수종과 병해 추가
- 사진 업로드 AI 판별: 잎·줄기 사진을 올리면 AI가 병해를 추정 (서버·API 키가 필요해 이번 범위에서 제외)

## 한계 및 비목표

1. **진단 범위가 제한됩니다.** 가로수 6종(+기타·모름)과 병해 13개만 다룹니다. 목록에 없는 병해는 진단하지 못하고, 증상이 비슷한 다른 병해와 혼동될 수 있습니다.
2. **참고용 1차 진단입니다.** 최종 확진과 약제 처방은 나무병원(나무의사)의 몫이므로, 페이지는 약제명·희석 배수를 제공하지 않고 관리 요령과 방제 적기만 안내합니다.
3. **기록이 남지 않고, 직접 적은 증상은 진단하지 않습니다.** 진단 기록 저장, 위치 기록, 사진 AI 판별은 구현하지 않으며, 페이지를 새로 고치면 체크·기록 칸·결과가 사라집니다. 기록 칸에 적은 증상은 일치율 계산에 쓰이지 않고 상담용 메모로만 표시됩니다. 기록이 필요하면 [결과 복사]나 [인쇄]를 사용합니다.

## 검증 방법

- **일치율을 연결표로 손계산한 값과 비교합니다.**
  1. 위 '병해 목록과 증상 연결표'를 보고 테스트할 수종과 증상 조합 3개를 정합니다. (예: 은행나무 + S7·S17·S11 체크 → 제설염 피해 3/3 = 100%, 깍지벌레·그을음병 1/3 = 33%, 줄기 썩음 1/4 = 25%)
  2. 각 병해의 일치율을 `맞은 증상 수 ÷ 전체 증상 수 × 100`(반올림)으로 직접 계산하고, 정렬 규칙에 따라 상위 3개 순서를 적습니다.
  3. 같은 조합을 페이지에서 체크하고 [진단하기]를 누른 뒤, 표시된 병해 이름·일치율·순서·위험도 색이 손계산 결과와 모두 같은지 확인합니다. 하나라도 다르면 연결표와 HTML의 데이터 중 어느 쪽이 틀렸는지 찾아 고칩니다.
