# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Claude (Claude Opus 5.5) / (캡처 파일명을 직접 적어 주세요)
- 더할 기능과 고른 이유:
  - 등급 칸 이름을 명작·재밌음·보통·별로로 바꾸고 설명과 영화 수를 붙임 → S·A·B·C 글자보다 친구들이 내 평가를 바로 알아볼 수 있어서
  - 영화 카드를 2:3 포스터 모양으로 바꾸고 제목·관람 등급·장르·‘포스터 없음’을 표시 → 실제 영화 포스터를 고르는 느낌을 주고, 영화 정보를 한 카드에서 볼 수 있어서
  - 장르별 포스터 색 → 어떤 장르를 높게 평가했는지 색만으로 한눈에 보여서
  - 장르 필터 → 장르별로 내 취향이 어떤지 골라 볼 수 있어서
  - 영화 추가 때 장르·관람 등급 고르기(고르지 않으면 ‘미정’) → 새 영화도 같은 정보를 갖게 하면서, 제목만 넣어도 추가된다는 원래 완성 기준을 지키려고
  - 직접 추가한 카드만 지우기 → 잘못 넣은 영화를 정리하되, ‘처음으로’를 누르면 처음 8편이 모두 돌아오는 기준을 지키려고
  - 밝은 화면 유지 → 원래 디자인과 이어지게 하려고

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - 처음 8편의 관람 등급을 AI가 기억으로 넣었는데, AI가 넣은 사실 정보를 어떻게 확인하는 게 좋을지 → 내용이 그럴듯해 보여도 틀릴 수 있어서
  - 기능을 바꾸면 기획서의 완성 기준도 같이 바꿔야 하는지 → S·A·B·C 표시를 지우면서 원래 기준과 화면이 어긋났기 때문에
