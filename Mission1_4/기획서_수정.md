# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 명작·재밌음·보통·별로 네 등급으로 나누어 내 취향을 정리합니다.
- 영화마다 장르와 관람 등급을 함께 보면서 내가 어떤 장르를 좋아하는지 한눈에 확인합니다.

## 화면과 동작

- 위에 명작·재밌음·보통·별로 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
  - 명작: 가장 높은 평가 / 재밌음: 좋게 본 영화 / 보통: 무난한 영화 / 별로: 아쉬웠던 영화
  - 등급 라벨 색은 명작 노랑, 재밌음 초록, 보통 파랑, 별로 회색입니다.
  - 등급 라벨에는 등급 이름, 한 줄 설명, 그 칸의 영화 수(예: 3편)를 보여 줍니다.
  - 빈 칸에는 ‘여기에 영화를 놓으세요’를 보여 줍니다.
- 영화 카드는 포스터 모양입니다.
  - 위쪽은 2:3 비율의 포스터 칸이고, 가운데에 제목과 ‘포스터 없음’ 표시가 들어갑니다.
  - 아래쪽에는 제목, 관람 등급(전체·12세·15세·청불·미정), 장르를 보여 줍니다.
  - 포스터 칸 색은 장르마다 다릅니다. (예: SF 파랑, 드라마 보라, 로맨스 분홍, 액션 빨강)
- 카드를 누르고 등급 이름을 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 장르·관람 등급을 고른 뒤 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다. 장르·관람 등급을 고르지 않으면 ‘미정’으로 들어갑니다.
- 직접 추가한 영화 카드는 오른쪽 위 ‘×’를 눌러 지울 수 있습니다. 처음 영화 8편은 지울 수 없습니다.
- 장르 버튼을 누르면 그 장르 카드만 또렷하게 보이고 나머지는 흐려집니다. ‘전체’를 누르면 모두 보입니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.
- 화면은 밝은 바탕을 유지합니다.

## 필요한 자료

| 제목 | 장르 | 관람 등급 |
|---|---|---|
| 기생충 | 스릴러 | 15세 |
| 인터스텔라 | SF | 12세 |
| 라라랜드 | 뮤지컬 | 12세 |
| 센과 치히로의 행방불명 | 애니메이션 | 전체 |
| 어벤져스: 엔드게임 | 액션 | 12세 |
| 범죄도시 | 범죄 | 청불 |
| 타이타닉 | 로맨스 | 15세 |
| 토이 스토리 | 애니메이션 | 전체 |

- 고를 수 있는 장르: 미정, 드라마, 스릴러, SF, 뮤지컬, 애니메이션, 액션, 범죄, 로맨스, 코미디, 공포, 판타지, 다큐멘터리
- 관람 등급은 국내 개봉 기준으로 넣었으며, 실제 등급은 한 번 더 확인이 필요합니다.

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 빈 제목은 추가하지 않습니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 등급 칸은 명작·재밌음·보통·별로로 표시되고, S·A·B·C 글자는 화면에 보이지 않습니다.
- 영화 카드의 포스터 칸은 2:3 비율이고, 제목·관람 등급·장르·‘포스터 없음’이 모두 보입니다.
- 장르가 다르면 포스터 칸 색도 다릅니다.
- 장르 버튼을 누르면 그 장르 카드만 또렷하게 보입니다.
- 직접 추가한 카드만 지울 수 있고, 처음 영화 8편에는 지우기 버튼이 없습니다.
- 각 등급 칸에 영화 수가 표시됩니다.
